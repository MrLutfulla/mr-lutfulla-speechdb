# **App Name**: SpeechCraft Studio

## Core Features:

- Audio Recording: Record new speech samples directly within the application using the device's microphone.
- Recording Playback: Play existing audio recordings to review collected speech data.
- Metadata Management: Add and edit metadata for each audio sample, including speaker ID, transcription, and any other relevant information.
- Data Export: Export the collected speech data and associated metadata in a standardized format for further analysis or use in machine learning models.

## Style Guidelines:

- Primary color: Forest green (#38A3A5) to promote a professional and focused atmosphere, without the common cliche of medical greens.
- Background color: Off-white (#F5F5F5) for a clean and non-distracting background.
- Accent color: A muted yellow-green (#7EC850), slightly analogous to the primary color, used to highlight key interactive elements without overpowering the interface.
- Font pairing: 'Inter' (sans-serif) for body text, 'Space Grotesk' (sans-serif) for headlines, giving a clean and professional yet modern feel.  The neutral sans-serif of 'Inter' avoids distracting from recorded speech, while the techy precision of 'Space Grotesk' subtly emphasizes the studio aspect.
- Use simple, consistent icons to represent actions like recording, playing, and saving.
- Organize the interface with clear sections for recording, playback, metadata editing, and data export. Each area is easily identifiable to speed learning and increase productivity.
- Use subtle animations to provide feedback on user interactions, such as button presses and data loading.
